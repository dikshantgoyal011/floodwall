# Floodwall

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Engineers evaluating Floodwall for governing high-volume, agent-driven infrastructure changes. Confirmed by the user for this redesign.

## Product Purpose

Meter agent-generated infrastructure changes, evaluate intents against policies, and record decisions in a tamper-evident ledger. The website helps visitors understand the model and inspect the Rust crate.

## Capabilities and Constraints

The Rust library provides admission control, scheduling, a deny-overrides gate, a human hold queue, and a cryptographic ledger. The website is a single React/Vite page published at floodwall.ai; `docs/` holds generated GitHub Pages output. It is an explanation of the library, not a connected operator console.

## Brand Commitments

Preserve the Floodwall name, brand mark, all existing website content, links, section order, and dynamically derived crate statistics. The user selected time.fyi and zero.xyz as references for a crisp black-and-white identity, neutral gray structure, and stronger framed navigation. Keep self-hosted Geist Variable for body, display, and UI text and Geist Mono Variable for code and diagram labels. Use green, amber, and red only for decision outcomes.

## Evidence on Hand

README.md, STATUS.md, GOALS.md, the Rust implementation, and the existing website content in site/src/. Main action: View the Crate. Do not invent commercial claims, customers, or performance figures.
