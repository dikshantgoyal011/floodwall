The model

Agents submit intents. Floodwall governs.

Admission

Per-agent token buckets and a bounded priority queue keep one loop from taking the whole lane.

Scheduler

Wide changes run alone, narrow ones run in parallel per resource, and a waiting change is never overtaken by lower-priority work.

Gate

A deny-overrides policy stack and a conflict check rule on every intent. Deferred changes wait on hold for a human.

Ledger

Every verdict is appended to a hash chain so retroactive edits break verification.

Policy gate

Many policies. One verdict.

Reference policies cover global destructive actions, blast-radius urgency, and resource allowlists. The policy trait stays small so teams can add rules that match their own release discipline. A deferred change is held, not dropped, until a human releases or expires it.

Tamper-evident ledger

Chained records. Independent proof.

Every decision, release, expiry, and outcome is appended with its evidence: the action, the reason, and each policy’s verdict. A retroactive edit anywhere in history breaks the chain.

  • SHA-256 hash chain: each record folds in the previous digest.
  • With a keyring, Ed25519 signatures prove which agent asked for what.
  • verify() replays the chain; verify_signatures() checks every signer.
